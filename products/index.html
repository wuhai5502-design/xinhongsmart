Which range fits which job

The five ranges overlap on purpose — a fingerprint module can go into a tablet, a handheld or a counter terminal — so the decision usually starts with where the device is used and what it has to capture, not with the model name.

RangeBuilt forTypical environment
Rugged tabletsScreen-heavy work: forms, maps, inspection, vehicle mountingWarehouse, yard, cab, outdoor site
Handheld PDAsScan-heavy work: picking, inventory, delivery, patrolAisles, vans, loading bays
Biometric devicesIdentity work: enrolment, verification, card and document readingCounters, field registration, border posts
Document devicesPaper that has to become a record: scanning, OCR, signingService halls, back offices, bank branches
POS terminalsPayment work: card acceptance, receipt printing, PIN and signature captureShop counters, restaurants, delivery, temporary lanes

Capture modules are specified before the housing and the mainboard are built, so the device is assembled around the module rather than adapted afterwards — that covers 2D scan engines, fingerprint sensors, NFC and RFID readers, ID card readers, and face recognition with liveness detection. If the job is identity capture rather than general computing, start with the biometric tablet overview; if the job needs a changed module, firmware or enclosure, see the OEM and ODM programme.
