Frequently asked questions

Which OS should we choose?
Android (RK3568) covers most counter applications with app-based workflows. Choose a domestic platform when procurement policy requires Xinchuang compliance; choose Windows when your verification software is a legacy Windows client. All run on the same chassis.
Is the ID card reader certified?
Yes — the standard reader follows the public-security resident ID card standard. Offline decoding options exist in this product family; confirm your network scenario at order time.
Can the face camera do liveness detection?
The binocular 2 MP camera option supports liveness detection. The monocular default covers standard photo capture; tell us which your anti-spoofing policy requires.
Can both screens show different content?
Yes — the two panels are independent USB displays; your application controls each side, e.g. visitor prompts on one, case handling on the other.
