OEM · ODM · HARDWARE

Hardware Customization for Rugged Terminals

Hardware customization is where most projects start: choose the modules, the interfaces, the memory tier and the radio configuration your deployment actually needs, and have the device built around that set instead of adapting a stock unit in the field. The options below are available on existing platforms as an OEM configuration; anything beyond them becomes design work on an ODM route.

Module availability varies by model — what fits the XH-500 tablet is not the same list as the XH-100 handheld. The set is confirmed against the platform you select, and any software impact is captured at the software customization stage.

INTERFACES

Interfaces customers ask for most

External ports

On the XH-400 platform the external set is RJ45 Ethernet, USB-A, USB Type-C, a DC 3.5 mm charging port, a reset pinhole and a hybrid SIM/TF tray, with two microphones — enough for most counter, kiosk and vehicle installations.

  • Wired RJ45 for installations that will not rely on Wi-Fi
  • USB-A for printers, meters and legacy peripherals
  • USB Type-C for charging and data

Internal headers for integrators

XH-400 also exposes internal USB, TTL serial, GPIO and SPI headers plus the 2D engine FPC inside the housing, so custom peripherals can be wired without external adapters hanging off the case.

  • USB × 3, TTL serial × 2, GPIO × 3, SPI × 1
  • Dedicated 2D scan engine FPC × 1
  • Where RS232 is required, TTL can be converted to RS232 for the project

An interface that the mainboard does not offer is a design change rather than a configuration change — that is the boundary between an OEM build and an ODM build with a new board.

FAQ

Hardware customization questions

Which modules can be specified on a rugged tablet or handheld PDA?
A 2D scan engine from Newland, Honeywell N3680 or Zebra 4710, FAP10 capacitive or FAP20 and FAP30 optical fingerprint capture, the second-generation Chinese ID card reader with an online version available, NFC at 13.56 MHz, and LF, HF or UHF RFID depending on the platform. Module availability varies by model, so the set is confirmed for the platform you select.
Can we add an interface the standard board does not have?
Internal USB, TTL serial, GPIO and SPI headers are already exposed inside the housing of some platforms, which covers many custom peripherals. An interface that the mainboard does not offer means electrical design work, so it moves the project from an OEM configuration to an ODM build with a new board.
Can the memory and storage configuration be changed?
Yes. Android 12 with 4 GB RAM and 64 GB storage is standard on the XH-500, and 6 GB plus 128 GB or 8 GB plus 128 GB are optional configurations, with the TF slot supporting expansion up to 512 GB. Available tiers depend on the platform, and the configuration is fixed before production starts.
Can LTE bands and chargers be matched to our market?
Yes. LTE band configuration and charger plug types are matched to the destination market, so the devices arrive usable with local carriers and sockets instead of being reworked after shipping.
